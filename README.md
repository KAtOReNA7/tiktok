# 古今人物锐评｜规范与新电脑接续

本仓库只保存PRD、项目方向、接续说明和通用资产，当前 **PRD V7.16**。完整选题调研、论点、口播、分镜、单集制作记录和成品存本地，不因定稿而上传，不为普通改稿创建Git提交。独立运营任务可将已授权的选题元数据、运营指标与评论分析写指定飞书，不把完整制作档案或动态数据提交Git。

## 先选择执行入口

- **老电脑继续制作（默认）**：只读取本地PRD、相关spec、本期定稿与制作记录，复用已有素材。不例行访问GitHub或Figma，不clone／fetch／pull，不检查远端版本或登录。新会话、新选题、新集数不触发同步；缺件先查本地并继续独立工作，见PRD 13.1.1。
- **新电脑首次初始化**：才执行下面的克隆／同步步骤，完成一次后切换本地续作。已有完整可用本地资料时不重复初始化。
- **规范更新**：用户明确要求同步或调整规范／接续时，独立执行PRD 13.1.2；普通单集制作不附带此任务。

读取AGENTS.md、CHAT_HANDOFF.md、START_HERE.md、PRD_V7.md和PROJECT_STATE.md，然后按用户当前任务执行。武松已完成，不重做；待确认文案不自动生图。

## 当前模板｜V3.2

发布封面固定为spec/cover_delivery.json的`COVER_DUAL_RATIO_FIXED_V1`，`cover_template_revision=1.0.0`：每集使用同一发布包中的3:4（1080×1440）与4:3（1440×1080）两套Figma母版及本地资产。各比例的母版ID、节点、底板、标题框与字形、漫画窗口、三位Q版锚点、朱印位置及图层顺序以该spec为准，禁止各电脑自行重新排版。每集只替换批准标题和漫画，按固定文字规则合成；封面三位原Q版装饰直接复用指定hosts_overlay，不逐期换装或重新生图；不得挪动窗口、角色锚点或印章，不得用系统字体静默替代。封面不套9:16正文锚点、不加口播字幕、不进素材映射或成片开头。缺件先查本地并报告具体文件／版本，继续不受影响的工作；不得退回自由设计封面，也不得在local_continue里访问GitHub或Figma。


新制作使用`RYP_STORY_MAIN_V3_2`及`STATIC_CAPTION_PAGES_V1`。每张9:16正文最终PNG常驻明确本集主题与该页实际口播；三位装饰扒边在右上、左下与底部三个方位和不同高度环抱整张模板，禁止同一排聚集；全部可见alpha位于主漫画窗外，实际交集必须为0。装饰可使用用户指定的顶部／底部非核心风险留白，核心标题、字幕、出处与正文仍避让。删除顶部“历史·原文回看”等内容类型，不换空话；出处使用暗色面板内浅灰字，不再用白条。准确文字由可编辑文本层确定性合成，不让imagegen绘字。读取本地spec/template.json、caption_style.json、program_visuals.json和assets/template/v3_2/。旧V3.1保留在spec/legacy/v3_1/与assets/template/v3_1/；旧V3保留在spec/legacy/v3/与assets/template/v3/，旧V2保留在spec/legacy/v2/与assets/template/v2/，仅供明确旧工程兼容，不混用。

原画按连续语义拆子页S01_01、S01_02（单页也_01），每页最多两行，长句分多图且可复用原画。两列CSV每行仅对应一张最终PNG的原稿片段；内部JSON记录parent_scene_id和视觉折行，逐父镜头及全稿拼接必须逐字符相等，不删改、重复或重排。CSV继续UTF-8单BOM、CRLF记录边界、标准转义与实际文件验收。

默认最终PNG已含静态字幕和扒边，不再等待最终人声做黑底MP4，也不让用户再叠同一句字幕或角色。用户用原配音安排图片顺序与时长；静态字幕不等于逐字高亮，不伪造时码。40秒上限、一次1.25倍、Q版身份、不做AI视频／音乐／动效继续有效。只重排的任务不改稿、不重配音、不重新生图；没有取得用户原画时不能声称重排完成。

新电脑首次初始化或明确rules_update才取得新版；老电脑日常只读本地，缺件报告具体路径，不自动联网或回退旧模板。规范发布不代表其他机器已经升级。

## 后续口播与镜头

`spec/narrative_retention.json` 定义 `RETENTION_INFO_V1`：首句直入人物行动冲突，保留影响责任的必要前因；正文逐段提供新事实、因果、后果、有效证据或有依据的相关反方及回应，至少有标题尚未讲完的真实发现。结尾回应开头、落到具体代价或问题，保持尖锐而不重复判词、不编反转。首图对应首句动作，后续镜头随信息推进，不能只换角度。

25–30秒与分段秒数仅为可撤销试验参考，默认40秒总上限和1.25倍速不变。无最终人声不编时码；voice_script只放正文，用户映射仍严格两列。规则用于后续起草与授权改写，已锁稿不自动改写，已完成作品不重做。栏目与实验分别执行下列配置；具体频次、排期与试验作品以当次任务为准。

## 三档节目与账号承诺

**熟悉的故事，算清主角得到什么、别人付出什么；有争议，回原文。**

- `MAIN_ACCOUNT` 名场面算账：一个事件的行动、证据和具体代价。
- `COUNTER_REPLY` 最强反方答疑：一条真实评论及其上下文，公平复述后用证据回答；无评论不伪造网友。
- `SAME_RULE_COMPARE` 同尺三案比较：先声明统一标准与范围，再依次比较三案，不拼旧稿、不混口径、不冒充全史排名。

编辑配置见`spec/program_editorial.json`，对应视觉配置见`spec/program_visuals.json`和`assets/template/v3_2/`；它们在V3.2几何上区分节目，保持Q版身份与静态字幕面板。各基础版式仍是镜头工具，不是节目数量。单集执行文件必须明写program_id和实际使用的栏目资产。

首批同时换模板与文案只作为组合试运行，后续按PRD 20.5做可比验证，具体排期、稿件和结果留运营工作区，不固化频次／配比。规则完成、素材完成、发布完成、效果验证分开记录。

## 素材映射CSV

素材映射仍严格两列。按`CSV_EXCEL_UTF8_BOM_V1`导出UTF-8单BOM、CRLF记录边界、标准CSV转义，字段内原始换行保持不变；严格解码、逐格读回并执行`python tools/validate_mapping_csv.py "实际交付素材映射.csv"`。多文件需显式逐一列出；不能仅验证空模板或网页预览。通用无损导出函数位于同一工具，见PRD 14.3。

### 本地固定封面套版与验收

固定封面工具需要Python和Pillow；优先复用当前可用环境，不要求每集重新安装。本次发布实际验收环境为Pillow 12.3.0／FreeType 2.14.3，最低Pillow要求见`tools/requirements.txt`。首次初始化或明确`rules_update`时，如本机缺Pillow，仅补一次：`python -m pip install -r tools/requirements.txt`。固定字体文件随发布包取得，不安装或依赖系统字体；日常`local_continue`不因依赖检查访问GitHub或Figma，缺件先本地查找并报告。

本期`cover_job.json`只保存在本地：写完整批准标题、实际原画路径及两比例明确的`title_lines`，各自逐行拼接必须完整还原标题，不删字、不缩小字。3:4最多三行，4:3最多四行；默认等比contain，使用cover裁切须在本地实际审过动作、脸、手与道具并记录。

`cover_job.json`使用以下字段结构；示例仅说明接口，不是本期采用稿，实际逐集填入真实ID、批准标题和存在的原画路径：

```json
{
  "topic_id": "本期ID",
  "part_number": 1,
  "revision": 1,
  "title": "人物：完整批准标题",
  "art_path": "本期原画.png",
  "variants": {
    "cover_3x4": {"title_lines": ["人物：", "完整批准标题"]},
    "cover_4x3": {"title_lines": ["人物：", "完整批准标题"]}
  }
}
```

每种比例只能用工具允许的内容和取景参数，不增加字体、角色层或版式覆盖字段。默认`art_fit=contain`；确已内部审过完整脸、手、动作及道具才在对应比例记录`art_fit=cover`、`crop_reviewed=true`和明确的`crop_anchor`。此确认由Codex内部记录，不要求用户逐图批准。工具只读取本地现行固定spec，不以另一份spec覆盖母版。

复用仓库工具运行：

```text
python tools/render_cover.py /绝对路径/cover_job.json --output-dir /绝对路径/交付
python tools/validate_cover.py --render-record /绝对路径/交付/本期ID_P01_封面渲染记录_v01.json
```

第二条必须指向第一条实际生成的记录，不能照抄示例文件名。工具输出两张PNG及本地渲染记录；封面绘制、文字测量、实际图字节和固定资产核验仍需结合手机缩略图内部验收。任务文件／记录／成品不进Git；工具缺失按具体缺件处理，不以手动自由设计替代。
