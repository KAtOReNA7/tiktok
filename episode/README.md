### 本地固定封面套版与验收

本期`cover_job.json`只保存在本地：写完整批准标题、实际原画路径，以及每种比例明确的`title_lines`和必填`highlight_line_indices`。各自逐行拼接必须完整还原标题，不删字、不改稿、不缩小字；3:4最多三行，4:3最多两行，均用92px字与104px行距，实际行组在固定标题框内垂直居中。强调索引为0起始的有效行号，选择1—2行承载本集关键冲突，不机械高亮末行；强调行黄底黑字，其余白字。实际字体测量溢出时先调整断行，仍放不下则说明具体溢出，不缩字或扩框。每种比例可用`art_path`覆盖顶层路径，但只能选择同集事件的不同构图。默认等比contain仅是兼容适配：实际缩略图若出现大面积留空或事件过小，须另选同集镜头／原画，不能机械接受；使用cover裁切须在本地实际审过动作、脸、手与道具并记录。

`cover_job.json`使用以下字段结构；示例仅说明接口，不是本期采用稿，实际逐集填入真实ID、批准标题和存在的原画路径：

```json
{
  "topic_id": "本期ID",
  "part_number": 1,
  "revision": 1,
  "title": "人物：完整批准标题",
  "art_path": "本期原画.png",
  "variants": {
    "cover_3x4": {"title_lines": ["人物：", "完整批准标题"], "highlight_line_indices": [1]},
    "cover_4x3": {"title_lines": ["人物：", "完整批准标题"], "highlight_line_indices": [1], "art_path": "本期横构图原画.png"}
  }
}
```

每种比例只使用工具允许的标题、强调索引、同集`art_path`与取景参数，不增加字体、角色层或版式覆盖字段。默认`art_fit=contain`；确已内部审过完整脸、手、动作及道具才在对应比例记录`art_fit=cover`、`crop_reviewed=true`和明确的`crop_anchor`。两比例可以使用同集不同原画以匹配各自画窗，不复用无关通用站姿或旧题漫画。裁切确认与缩略图检查由Codex内部记录，不要求用户逐图批准。工具只读取本地现行固定spec，不以另一份spec覆盖母版。

复用仓库工具运行：

```text
python tools/render_cover.py /绝对路径/cover_job.json --output-dir /绝对路径/交付
python tools/validate_cover.py --render-record /绝对路径/交付/本期ID_P01_封面渲染记录_v01.json
```

第二条必须指向第一条实际生成的记录，不能照抄示例文件名。工具输出两张PNG及本地渲染记录；封面绘制、文字测量、实际图字节和固定资产核验仍需结合手机缩略图内部验收。任务文件／记录／成品不进Git；工具缺失按具体缺件处理，不以手动自由设计替代。
