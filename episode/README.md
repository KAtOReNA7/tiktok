# 本期空白模板｜V7.8

brief.yaml记录本期范围和40秒默认上限；parts.csv逐集记录片头模式、独立结尾、封面、一句话简介和黑底字幕视频。它们是空白字段，不是已完成内容。

brief中的hosts_cast记录“固定Q版演员→剧情角色”，身份标准读取spec/character_identity.json。本地分镜在现有composition／identity_ref等字段说明实际出镜者与参考用途；production_log逐图记实际输入、脸与身体检查、是否通过。需要纠偏时按需记录内部定妆文件及视觉检查结论，null不是通过；Codex自行修正后继续完整交付，不设置角色确认节点。拒绝成人化或换脸素材，不能把身份验收字段加到用户两列映射中。

scene_map.csv是给用户剪辑用的素材映射，只保留“插图编号、对应口播”两列。每行写稳定的插图编号（如S01）及该图对应的完整定稿原文，按口播顺序排列；图片文件名带同一编号。不能写摘要、省略号或“开头两句”。不加入时间、路径、版本、状态、备注等列，也不预留空列。收到配音后这张表仍保持两列；分镜制作信息及字幕时码分别留在自己的制作文件中。

收到最终人声再定时渲染黑底字幕MP4；辅助SRT不替代MP4。局部补字幕需同时给出原视频放置起点。封面使用同模板但针对该集设计有张力的漫画。

本目录只保留空白模板，复制到本地工作根后再填写。工作资料放本地episodes/{选题ID}/，最终文件集中在本地交付/{选题ID}_{短名}/；填写后的副本与所有本期内容不提交Git，按集号分目录并命名。不生成压缩包，不生成音效、配乐、轻动效或建议表。

production_log.md集中记录实际提示词、参考用途、版本、简短QA、耗时与缺件；交付/内的00_交付清单.md说明每集当前使用文件。只补字幕的任务不强行重做封面或其他既有资产。

在已有本地记录中注明本次模式与使用的本地规范版本即可。新电脑首次记录规范目录、工作目录和已取得的提交号；老电脑沿用，不为补齐版本号访问GitHub，也不每集重跑初始化。具体指令按新电脑首次版／老电脑继续制作版分别命名，均只放本地。

## 新制作任务的模板要求

本空白brief默认 `prd_version: '7.8'`、`template_id: RYP_STORY_MAIN_V2`。选用封面开场／正文大画面／局部特写／原文证据中的适合镜头版式，不强制全用；实际几何、资产路径和文字规则读取本地spec/template.json。正文不常驻巨大整集标题或巨型页脚。

四种空底板为主画面镂空的透明覆盖层，置于独立漫画之上、口播字幕之下，不烙入示例文字、原画或签名；均保留x96/y1408、776×128、#1C1C1C空黑字幕槽，示例文字默认关闭，给后续字幕MP4覆盖，人物、气泡、证据和出处不得占用。V2三位底部签名使用独立小尺寸层，不沿用旧全屏外缘overlay；剧情出镜仍为三位Q版本人按题换装。

具体新／老电脑执行文件都须明示V7.8／V2要求。新电脑首次取得一次后本地续作；老电脑缺新规范或资产先查本地并报告具体缺件，不静默回退旧底板或自行访问GitHub/Figma；只有用户明确rules_update才一次性升级。当前机器升级不代表其他机器升级。此默认只针对新制作任务；已完成不重做，在制旧版按用户当前指示处理。
