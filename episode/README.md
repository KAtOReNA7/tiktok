# 本期空白模板｜V7.12

brief.yaml记录本期范围和40秒默认上限；parts.csv逐集记录片头模式、独立结尾、封面、一句话简介和静态字幕分页计划、最终PNG目录及字幕profile。它们是空白字段，不是已完成内容。

brief中的hosts_cast记录“固定Q版演员→剧情角色”，身份标准读取spec/character_identity.json。本地分镜在现有composition／identity_ref等字段说明实际出镜者与参考用途；production_log逐图记实际输入、脸与身体检查、是否通过。需要纠偏时按需记录内部定妆文件及视觉检查结论，null不是通过；Codex自行修正后继续完整交付，不设置角色确认节点。拒绝成人化或换脸素材，不能把身份验收字段加到用户两列映射中。

scene_map.csv是给用户剪辑用的素材映射，只保留“插图编号、对应口播”两列。每行写最终子页编号（如S01_01，单页也带_01）及该页显示的连续原稿片段，按口播顺序排列；图片文件名带同一编号。不能写摘要、省略号或“开头两句”。不加入时间、路径、版本、状态、备注等列，也不预留空列。内部page_plan保留parent_scene_id与视觉换行；各父镜头及整集按顺序拼接须逐字符等于采用稿，不将新增视觉换行写入映射。用户按原配音安排图长，内部信息不加入CSV。

导出执行CSV_EXCEL_UTF8_BOM_V1（PRD 14.3）：UTF-8恰一个BOM，记录边界CRLF，标准CSV引号转义；原字段内换行、标点和编号不变。可用tools/validate_mapping_csv.py的export_mapping_csv无损导出，必须对本期真实CSV运行独立校验并逐格核稿。可对真实page_plan运行tools/validate_caption_pages.py，核对父镜头／全稿保真及实际CSV逐格一致；该工具只验文字映射，不能代替PNG看图、字体实测或声音验收。空模板才可用--allow-header-only，用户交付不能沿用该例外；禁止errors=replace／ignore，不转GBK，不重复加BOM。

默认交静态语义字幕最终PNG，不等待人声；静态页不能称为逐字高亮。用户按原配音安排时长，无音频不编时码。封面与成片页各自命名，只有实际播出的字幕页进入映射。

本目录只保留空白模板，复制到本地工作根后再填写。工作资料放本地episodes/{选题ID}/，最终文件集中在本地交付/{选题ID}_{短名}/；填写后的副本与所有本期内容不提交Git，按集号分目录并命名。不生成压缩包，不生成音效、配乐、轻动效或建议表。

production_log.md集中记录实际提示词、参考用途、版本、简短QA、耗时与缺件；交付/内的00_交付清单.md说明每集当前使用文件。只补字幕的任务不强行重做封面或其他既有资产。

在已有本地记录中注明本次模式与使用的本地规范版本即可。新电脑首次记录规范目录、工作目录和已取得的提交号；老电脑沿用，不为补齐版本号访问GitHub，也不每集重跑初始化。具体指令按新电脑首次版／老电脑继续制作版分别命名，均只放本地。

## 新制作任务的模板要求

新制作使用`RYP_STORY_MAIN_V3`及`STATIC_CAPTION_PAGES_V1`。每张最终PNG常驻明确本集主题、该页实际口播和三位分散扒边，删除顶部冗余品牌／口号；准确文字由可编辑文本层确定性合成，不让imagegen绘字。读取本地spec/template.json、caption_style.json、program_visuals.json和assets/template/v3/。旧V2配置与资产仅在spec/legacy/v2/、assets/template/v2/兼容保存，不混用。

原画按连续语义拆子页S01_01、S01_02（单页也_01），每页最多两行，长句分多图且可复用原画。两列CSV每行仅对应一张最终PNG的原稿片段；内部JSON记录parent_scene_id和视觉折行，逐父镜头及全稿拼接必须逐字符相等，不删改、重复或重排。CSV继续UTF-8单BOM、CRLF记录边界、标准转义与实际文件验收。

默认最终PNG已含静态字幕和扒边，不再等待最终人声做黑底MP4，也不让用户再叠同一句字幕或角色。用户用原配音安排图片顺序与时长；静态字幕不等于逐字高亮，不伪造时码。40秒上限、一次1.25倍、Q版身份、不做AI视频／音乐／动效继续有效。只重排的任务不改稿、不重配音、不重新生图；没有取得用户原画时不能声称重排完成。

新电脑首次初始化或明确rules_update才取得新版；老电脑日常只读本地，缺件报告具体路径，不自动联网或回退旧模板。规范发布不代表其他机器已经升级。

## 新起草与授权改写的口播要求

brief默认 `narrative_profile_id: RETENTION_INFO_V1`，读取 `spec/narrative_retention.json`。首句给具体人物与行动冲突，必要前因不能省略到歪曲责任。正文每段推进事实、因果、后果、有效证据或相关最强反方及回应；至少有标题没讲完的真实发现，没有有据可查的反方或第二发现不硬造。结尾回应开头并落具体代价或问题，保留尖锐，不重复判词。已锁稿不自动改写。

25–30秒目标及0–2／2–5／5–12／12–20／20–28秒只是可撤销试验参考，不是实测时码或强制五段式。brief中的trial_target_duration_s、info_gain_review只是按需填写的本地记录，null不代表已检查或通过；不要求为凑字段另建复杂框架。原40秒总上限与1.25倍速不变，无最终声音不得编造时间。voice_script只含完整口播正文，内部检查、镜头指令和时间记录放本地制作文件，不混进配音正文。

首图表现首句动作或冲突；后续段落带来新信息时，镜头须展示相应新动作、对象、后果或证据，不能只换景别重复同一内容。信息增量检查按需记在production_log.md，用户scene_map.csv仍严格“插图编号、对应口播”两列。
