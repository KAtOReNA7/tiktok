# V2 栏目扩展底板

这些是通用 UI 覆盖层，不是已经制作好的单集画面。几何与字体以 `spec/program_visuals.json` 为准。

- `counter_question_base_1080x1920.png`：最强反方答疑，问题阶段。
- `counter_reply_base_1080x1920.png`：最强反方答疑，证据答复阶段。
- `compare_standard_base_1080x1920.png`：同尺三案比较，先交代统一标准。
- `compare_reveal_1_base_1080x1920.png`、`compare_reveal_2_base_1080x1920.png`、`compare_reveal_3_base_1080x1920.png`：当前案例依次高亮，静态切换。

主线 `MAIN_ACCOUNT` 仍复用父目录四张 V2 底板，不把这些镜头版式算成新的栏目。

所有新增底板为 1080×1920 RGBA，主画面窗口真实透明，保留固定 UI 卡片与空黑字幕槽。底板不含原画、签名和任何文字；品牌、朱印字、栏目、问题、证据、案例名及出处须按 spec 单独排版。只叠一张全屏底板，不能再叠主线底板。字幕槽固定为 x96 / y1408 / 776×128、#1C1C1C，禁止挪位。
