# 运营任务接续接口

适用PRD：V7.5。更新：2026-09-23。本文件只保存通用接口；动态指标、候选清单、日报、收件配置与连接信息留在既有运营工作区和指定飞书中。

## 接续现行资料

| 固定文件名 | 用途 |
| --- | --- |
| 三只不服_运营工作流.md | 已授权日程、数据范围、飞书结构、每日步骤、选题试行状态与阶段方向 |
| 三只不服_运营评级规则.md | 运营评级定义、试行阈值、来源等级、窗口和例外口径 |
| 三只不服_定时运行状态.json | 真实运行结果、采集时点、写表与邮件状态、同日去重与恢复点 |

以上是运营工作区中的持久文件，不在Git仓库中；通过既有任务保存的稳定文件身份读取现行版本。标题版本低于文件内容版本的历史命名不再作为入口。更名保留身份并更新任务引用；正文保留版本与修订记录。日报／独立快照用“账号名_用途_YYYY-MM-DD[_HHmm].扩展名”，日期为Asia/Shanghai，不覆盖前次真实采集时间。

接续前先辨认任务：制作任务继续本地生产；运营任务读取现行运营规格与最后一次运行状态。每天13:00是已授权运营任务的启动时间，不是邮件保证送达时间。复用既有定时任务，不复制新任务；是否成功运行以真实运行结果为准。

## 数据与反馈的最低要求

- 当次前台公开且已发布作品为唯一活动分析范围；隐藏、私密、草稿及未发布定时作品排除。缺页或分页失败先复核，可见性退出与表现下降分开。
- 每条作品保留真实ID、实际采集时刻、数据统计时点、发布时间、时长、可得指标及缺项；累计、自然日和可比快照增量分开，约数不能当精确值。
- 评论少时尽量完整读取；多时分热门、最新、早期、回复扩大采样，记录抽样范围、数量与缺口。原话、分类与分析分开；辩护、纠错、理解障碍、需求和情绪分别判断。
- 每条作品给运营评级、结论和下一步，R认知层级、P选题优先级、S/A/B/C/D作品评级分开。评级阈值与24小时／72小时／7天等观察窗口是运营规格中的试行实施方案，不是平台官方规则；不从一条爆款推断整个类别成立。
- 标签比较标明具体作品与样本量，匹配时长、龄期和流量性质；试验尽量一次主要比较一个变量，指标与评论共同验证。
- 日报概括变化和行动，完整逐作品分析留指定飞书；缺数与未完成步骤明确报告，旧值不冒充当天结果。

## 选题流程与阶段方向

PRD 2.4的人物优先流程从2026-09-23起为阶段性试行；后续效果不好，用户可调整或删除。停用后同步维护工作流与任务提示，不保留强制人物入口；事实核验与可比性原则继续有效。

具体水浒优先、人物暂缓等方向只在带日期的运营记录中维护，不成为本接口的永久名单。已确认稿件不重新当作待选新题，制作完成／已发布状态须有实际记录，不根据选题获批推断。

## 写入范围

沿用指定台账与稳定记录ID，新增先按人物、具体事件和来源版本查重；标题可以修改，不作唯一匹配键。人物储备、事件线索、已初核、用户确认制作、已发布与复盘结果分别记录。选题元数据可含标题、标签、观点摘要、来源链接、依据与边界、状态、假设、优先级和下一步；作品数据与评论分析按授权更新。

此接口不把完整口播、单集生产档案、素材和成片纳入远端存储，也不扩大既有运营任务到自动制作、发布或账号互动。日常运营不访问GitHub；只有独立授权的规范更新才维护此文件。
