# 三只不服｜人工日选题协议

协议：MANUAL_TOPIC_REVIEW_V1，修订1.1；生效：2026-10-12（Asia/Shanghai）。本文件保存运营方向与接续方法，不是单集制作SOP；实际候选、稿件、评论、指标与排期留在本地／授权运营工作区及既有飞书。后续可依据用户决定与新样本修订。

## 本次决定与证据边界

恢复每天人工选题：既有自动化继续采集、复盘、检索与整理候选；用户人工决定今天采用哪些具体事件和角度。候选排序、编辑高分或数据达线均不自动成为制作、锁稿、发布或固定排期授权。未确认状态统一为“待人工选择”；已获明确确认的具体选题直接进入讨论／制作，不重复要求确认角色形象。

恢复的理由是近期传播不理想、用户认为自动候选缺少吸引力与争点，不是已经证明“自动化导致流量下降”。比较须匹配真实龄期、时长与分发条件，并保留未标注人工／自动来源的缺口；不能把少数近期好完播推广为口播与制作已全面改善。完播、跳出、评论、分享、关注和分发分别诊断，单一指标不代替账号增长。

## 每天如何共同选题

1. **从昨天到今天。** 既有13:00任务先完成全部公开作品指标及重点评论复盘，指出一条有证据的新发现、一条反例和今天需要验证的问题。已锁稿／已排期不改，不机械补足每日固定条数。
2. **先定大众评价，再去外面找。** 按[账号核心](editorial_cognition.md)写出大众根本评价和一句反向观点；优先公众号、营销号、标题党、自媒体评论等传播入口，百科仅作辅助。检索本赛道真实可访问的热门称赞、争议批评及相关回复；优先20—40秒作品用于研究表达，更长视频只提供事件线索。记录链接、创作者、实际发表日期、采集日期、可见互动数字／约数、表达的共识与实际已读反方。无法核验数据的条目只叫“线索／传播入口”，不叫近期热点或爆款。旧视频有传播价值可以用，但必须注明旧作；不要把抓取时间当发布时间。不直接改写整篇他人文案，独立回原文组织观点。
3. **交4—6张候选卡。** 数量服从真实材料，证据不足就减少；不得为填数重复人物事件、虚构热度或随意拼接。每张卡填写下述最小信息，简短但有区分。
4. **用户人工取舍。** 用户从卡片中指定采用／暂缓／改角度；自动化可以标编辑建议顺序，但不能将建议改成“已确认”或直接生成完整投产批次。用户的理由进入已有长备注，保留拒绝样本与原因，不删除失败记录。
5. **采用后写稿。** 先给标题、完整口播、来源边界与上线前百分制评审；锁稿后再按相应新／老电脑模式交完整TXT／MD制作文件。实际出演执行DORO_MAIN_CRITICIZED_V1，主角演员与题材评价立场分开记录。
6. **发布后回查。** 将真实ID与选择来源／理由、最终稿版本关联，按现行24—48小时、72—96小时及成熟窗口检验。分别回答是否吸引观看、是否产生围绕核心冲突的立场、是否分享／关注；不足以判断时如实记观察中。

## 候选卡的必要信息

| 项目 | 必须回答的问题 |
| --- | --- |
| 人物＋具体事件＋来源性质 | 这是谁、哪一件事，正史／小说／传说／假设论证是什么？与已做事件是否重复？ |
| 原有共识 | 观众通常在称赞或责骂什么？来自真实视频／评论，还是编辑预判？ |
| 本片一句反向观点 | 直接挑战哪一项大众评价？删掉事件细节，这句话是否仍值得观众反驳或追问？ |
| 最强辩护＋尖锐追问 | 支持者有哪条合理事实或价值理由？本片能追问哪一项代价／责任？不编网友、不设稻草人。 |
| 普通人站队入口 | 对应感恩、守规则、用人、亲情、公平、责任等哪个能迅速理解的问题？避免多层冷门人名解释。 |
| 首句与后续材料 | 第一句是否亮出核心反向观点，随后哪项事实支撑它？正文还能提供什么证据或后果？ |
| 来源与风险边界 | 原文能证明到哪里，哪条前因会改变责任，是否有直接反证、是否已核？ |
| 人工选择与验证 | 建议／待选／已确认／暂缓分别记录；预判最可能出现的两种评论与如何验证。 |

复用现有选题实验表的选题、状态、下一步、栏目、批内顺序、入选理由六列。详细两方论据、链接、来源性质、热度核验、选择者与选择时刻、拒绝原因和验证放既有长备注／记录详情；不新增表或擅自扩字段。不能根据当前没有评论就倒推观众支持／反对。

## 选角度的编辑判断

- 优先**被广泛认同的人物评价与本片反向观点之间的冲突**。先说清不服哪句话，再以具体行动、能力或代价支持；猎奇、杀人数量、弱者受害不能单独决定选题。
- 正面叙事先找谁付代价和责任边界；负面叙事先找实际能力、效果与被遮蔽的功劳。人物本来就口碑复杂时，必须有具体新发现；不要靠更狠的标题伪造反差。
- 写稿前记录观众为什么仍认同原评价，作为编辑参考；不强制每个事件都有合理辩护，更不因“这件事当然坏”而淘汰能够撼动人物根本评价的题。正文不必硬塞双方辩论，已知会改变责任的前因仍须保留。
- **事实与评价分层。** 原文、前因、数量、责任归属明确；尖锐评价可以挑战常识、保留价值判断空间。不得省略会直接改变责任判断的事实、编动机、拼接引文或用假史料诱导纠错。
- 结尾回到同一人物评价；有证据后的“还配叫好汉吗”可以保留，删无推进的同义空骂。主线首句可直接用标题核心判断，不对观众第二人称训话，不强要评论。
- 每次区分候选吸引力与口播执行质量。既有ES1.0编辑分继续适用，不临时改权重或把候选卡新项目拼成另一种总分；高分不代替用户人工选定。

## 新阶段的验证与调整

本阶段记录manual_user_choice／assistant_suggested_user_choice／来源未知，采用依据和日期；历史没有记录的不补造。新增选择标签放现有长备注，最少比较各组真实窗口、时长、样本量、播放中位数、每千播放评论／分享／关注及跳出／完播；无法按来源拆组时明确缺口。

评论深读保留现行分层抽样、原话、上下文、反例和六类需求。额外回答争论是否围绕本片核心取舍、是否出现双方理由、是否只是纠错／跑题或少数人重复回复。没有稳定观众标识不估算独立人数，没有编码总体不报整体立场比例。不能用刻意错漏换高评论，也不能把评论率高但留人／分享弱的作品称成功复制。

每日最多提出一项主要下一步，下一篇选择可检验新事件；没有实际采用、真实ID或成熟窗口不能提前宣布人工选题已有效。候选检索由自动化辅助，最终采用持续由用户人工决定。
