# 三只不服｜先挑战人物评价，再讲事

标识：`EDITORIAL_COGNITION_V1`；修订：1.0；生效：2026-10-12（Asia/Shanghai）。本文件记录用户在当日对账号核心的明确纠正，供策划、写稿、审稿、运营复盘和后续会话共同读取。叙事接口为`RETENTION_INFO_V1`修订1.2。

## 账号到底要做什么

**把观众对熟悉人物最认定的那句评价拿出来质疑，再用具体故事撑住这个判断。**

用户给出的基准是：“武松算哪门子好汉？”武松在大众故事印象中几乎就是“好汉”的代表，第一句话直接动摇这个评价。观众先想反驳、辩护或听下去，厨房丫鬟、求饶的马夫等细节随后成为论据。只总结为“武松杀了丫鬟”“主角让弱者付出代价”，会漏掉这个选题最重要的吸引力。

这里的“事实放在后面”指选题组织和口播呈现顺序：先有值得争的反向观点，再找能支撑它的具体材料，正文及时兑现。它不表示先宣布未经调查的事实，也不要求拖延证据到视频结尾。

账号优先追求吸引观看和讨论，允许尖锐、挑衅、有立场的表达。公众号、营销号、标题党、自媒体评论、小说和野史都是有效的选题入口；不能只翻百科或维基百科。学术完备性不作候选的首要排名项；依然区分小说、传闻、史实及编辑判断，不造引文、出处、热度或明知相反的事实。

## 选题先回答三个问题

1. **观众原本认定什么？** 写成完整判断，如“武松是好汉”，不要只填“武松知名度高”。认知依据注明来自教材／经典影视／长期传播印象／实际评论，或只是编辑预判；不能声称人人都这样想。
2. **本片到底反对哪一句？** 用一句自然口语直接挑战同一项评价。认为人物做过坏事，未必能反驳其“聪明”；名号和论据必须对应。删掉事件细节，观点仍应能让熟悉人物的人产生明确异议。
3. **接下来凭什么这样说？** 找最有力、最易讲清的事件和细节，使观众能评价这句主张。只有猎奇事件、残酷数字或弱者受害，尚不足以成为本账号的优先题。

推荐顺序为：根本人设的认同强度与可争性 → 反向观点是否直接击中该评价 → 支撑事件的冲击力与理解成本 → 与已做内容的区别。不要临时造爆款概率或另一套百分制。既有审稿五项权重保持，但“开头兴趣”必须检查所挑战的评价。

大众评价可能正面，也可能负面。负面人物的新角度可以挑战其“无能”“愚忠”等印象，不必把整个人洗成好人。口碑早已复杂、大家本就这样骂的人物，反向观点需要重新检查，不能仅靠更狠的词凑反差。

## 标题和口播怎么写

- **主线锐评先亮观点。** 允许标题与首句使用同一句核心判断，包括“武松算哪门子好汉？”。它已经承担认知冲突，不得因为“首句必须动作”或“不能重复标题”而删掉。下一句尽快给具体事，必要关系随讲随补。
- 核心结构是“反向判断 → 关键事实及必要前因 → 进一步证据／后果 → 回到同一个评价”。这不是强制四句、四镜或固定秒数。答疑与比较沿用各自组织方法，也须说清正在争哪项评价。
- 结尾可以再次追问人物名号或资格；有了前面的证据，呼应开头不自动算废话。反复同义骂人、没有推进的重复才删。
- 一件有分量的事可以支持对人物名号的质疑，不强制先凑齐多个故事才让观点出现。若声称一生一贯如此、每次如此或所有人如此，材料必须支持对应范围；不能以单例替代此类事实概括。
- 反讽、正话反说只是可选表达，不再强制“表面夸赞、实际贬损”，也不把所有题目压成“人物：前半句，后半句”。用户已确认标题／稿件按授权范围处理。
- 画面承接受质疑的人物和本片关键证据。首句为判断时，首图可以直接展示人物及后文证据场景，不要求把首句硬改成动作句。制作尺寸、字幕、演员与封面资产仍按本机已批准的制作版本。

## 中文写作去模板味

本次检索提炼的是编辑办法，不是AI检测规避办法，不承诺任何检测分数。

1. **先把态度说清。** 读完开头应知道作者到底不服什么；不要用漂亮但没有具体主张的文案代替判断。
2. **做减法。** 删掉没有信息的铺垫、解释和升华；别靠“更离谱的还在后面”“颠覆认知”“底层逻辑”制造悬念。
3. **检查可替换的人名。** “真周到／一步到位／安排了／跟着买单”等词并非一律禁用；若整批靠这些词调侃，换个人名照样成立，就重写。不要把去模板味再变成机械禁词表。
4. **不强凑工整。** 标题可以一句话，长短和句式服从意思，不强制冒号、对仗、反问、三段式或每句反转。说得通的短句原样留下，不为润色换同义词。
5. **用人物的动作把观点撑住。** 正文交代谁说了什么、做了什么、怎样处置；少用抽象名词和“人性的复杂”等总结。
6. **按口播念一遍。** 改掉绕口、翻译腔和连续排比。保持作者自己的判断与节奏，不硬塞“家人们”“说白了”、错别字或虚构经历来装口语。

候选输出优先展示：核心首句／标题、被挑战的常见判断、后续证据和推荐理由。完整来源边界留在简短备注或当地调研文件，不让考据说明淹没选题。

## 复盘与接续

- 复盘同时记录“大众判断—本片反向判断—首句原文—支撑事实”；不能只按人物、作品、杀人、弱者等题材标签总结成功。
- “武松算哪门子好汉？”是用户确认的方向基准和优先复测假设。既有高播放支持值得继续研究，不能单凭一条作品宣布已证明首句是唯一原因。复投保留核心首句，记录实际修改项；多项同时变化仍是组合试运行。
- 2026-10-12用户已提出武松原条轻改复投，旧“武松已完成、不重做”不应阻止这项授权。原版保留，复投另记版本；不能据此批量重做其他作品，也不能把候选当成发布授权。
- 新会话先读本文件，再读人工选题、叙事与栏目spec。老电脑仍按local_continue；用户明确要求同步规范才执行rules_update。
- 本次是内容方向修订，独立于PRD／封面包编号。此前交付的本地V7.19升级文件不等于GitHub已发布；已有较新制作资产的电脑采用此内容规则时，不因仓库基础制作版本为V7.18而回退封面或其他资产。本次不发布V7.19封面包。
- 实际候选、完整口播、每日指标和评论留本地／已授权运营工作区，不进规范仓库；此处只保留解释规则所需的最短基准。
